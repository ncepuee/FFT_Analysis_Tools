# FFT分析使用方法

## 数据保存

首先将Simulink的仿真修改为取消单一仿真输出

然后将需要进行傅里叶分析的波形作为单独数据导出

导出通过`to workspace`模块，类型选择`带时间的结构体`

运行仿真之后，将变量区的`to workspace`变量存到另存为mat文件

⚠注意事项：请单独保存需要进行傅里叶分析的变量为mat文件！

# FFT分析流程
之后运行`main.m`代码，加载保存的mat文件，代码会首先运行`DataExtractor`函数

识别弹出需要加载的变量，选择需要分析的mat文件，之后会自动识别mat文件里的变量名称

并提取对应的time时间向量和波形向量。

最后利用performFFT函数进行傅里叶分析。

performFFT(time, waveform,50,10,2,2000);

其中50表示基波周期（频率分辨率），10表示需要分析的周波数，2表示从2s开始进行数据取值，2000表示傅里叶分析显示的频谱范围。
